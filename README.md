# Prácticas FCT · 1º SEA

Herramienta de gestión de las prácticas (FCT) del 1º de CFGS Sistemas Electrotécnicos y Automatizados — CIFP Virgen de Las Nieves.

- Preferencias del alumnado, reparto automático (método húngaro) con ajustes manuales.
- Base de datos de empresas, conciertos, plazas, turnos y contactos.
- Mapa con OpenStreetMap, direcciones del IGN (CartoCiudad) y tiempos en coche (OSRM).

Los **datos no están en este repositorio**: se guardan en Supabase con acceso restringido (inicio de sesión + lista de emails autorizados + reglas RLS). Este repositorio solo contiene el código de la página.
